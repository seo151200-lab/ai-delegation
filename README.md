# AI 위임 유형 진단 (프로토타입)

대학생이 보고서·글쓰기 과제를 할 때 생성형 AI에 각 작업을 얼마나 맡기는지 진단하고, 진단한 유형에 맞춰 과제를 단계별로 진행하도록 돕는 웹 프로토타입입니다.

## 구성 (5단계)
1. **과제** – 보고서 / 글쓰기 과제 선택
2. **위임 정도** – 8개 작업별 AI 위임 정도(0~4점)와 학습 목표 체크
3. **나에 대해** – AI 신뢰, 검증 자신감, 배움 중시, 마감 기간
4. **결과** – 나의 위임 유형과 네 가지 유형(전방위 위임형, 정보·정리 위임형, 저위임형, 과제 위임형)의 특징
5. **과제 작업실** – 과제 안내문 PDF를 띄워 놓고 작업별 안내·확인 항목과 함께 작성

## 실행
설치가 필요 없습니다. `index.html`을 브라우저로 열거나 GitHub Pages로 배포하면 됩니다.
응답과 작성 내용은 브라우저(localStorage)에만 저장되고, PDF는 브라우저 안에서만 열립니다.
